Portfolio for CS 320

When coding, it is important to ensure you understand the scope of the project from the beginning to reduce the number of assumptions and potential errors from entering your project.  While coding, the use of automated testing is paramount to ensure you are validating the functionality of the program itself, throughout the entire coding process.  These types of tests can also ensure security, as input validation can be part of your testing process.

Interpretting user needs can come from detailed specifications provided either in writing or through user interviews.  This allows the programming team to understand the desired end use case to ensure the product they create meets those requirements.  In having conversations, it also allows both sides to truly understand the why behind the ask, and can also allow the expertise of the team to help best meet those goals.

I personally try to approach designing software with the end user in mind.  It is not only about meeting the written requirements, but ensuring that the end product aligns with the actual use cases it is designed for.
